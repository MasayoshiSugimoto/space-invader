# Space Invader

This project is the game `Space Invader` running in your terminal.

It is written in C on Ubuntu. It may work on other distribution.


## Dependencies

This program depends on `ncurses`. It has been tested with version 6.4.20240113.

You can install on Ubuntu using:

	sudo apt install libncurses5-dev libncursesw5-dev


## How to build

```bash
cd space-invader
make
```

## How to execute

```bash
cd space-invader
make run
```

## How to clean

```bash
cd space-invader
make clean
```

## How to play

| Button      | Usage																						|
|-------------|-------------------------------------------------|
| Left Arrow	| Move left.																			|
| Right Arrow	| Move right.																			|
| Space				| Fire.																						|
